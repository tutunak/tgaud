Import members from tgstats

The Bot API cannot list the members a chat already has, so tgaud learns people only from joins and leaves since the bot became an admin. tgstats collect lists them with your own Telegram account; upload the tgstats.db it wrote, and tgaud reconciles those members with what it recorded.

What is imported

  • The latest snapshot of each chat in the file, for chats tgaud tracks. Earlier snapshots in the file are left alone, and so are tracked chats the file does not have.
  • Only snapshots of this tgstats version: an older one recorded only when its collection ended, which can contradict leaves tgaud saw meanwhile. Collect again with tgstats collect.
  • A snapshot that is not newer than one tgaud already has for the chat, or one already imported, is skipped: uploading the same file twice imports nothing new.
  • People removed with tgaud forget-user are never brought back. {% if not names %}Names and usernames are not stored (TGAUD_STORE_NAMES is off).{% endif %}
  • A chat with more than {{ ceiling }} members in one snapshot is refused: one chat's import is one database transaction, kept under {{ seconds|int }} s.

What happens next

The result page lists every chat of the file with what happened to it. The reconciler then applies each imported snapshot, usually within minutes: members it lists become known stays, a complete listing lets tgaud doubt (and probe) stays it does not list, and the coverage report shows known against Telegram's count.
